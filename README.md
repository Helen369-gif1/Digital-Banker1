# Digital Banker — Move Money Home (v2, calibrated)

Прототип экрана "Move Money Home", пересобранный под фактический
визуальный язык экранов Send Money / Payees, с использованием
предоставленных фоновых изображений (не CSS-градиент).

## Как открыть
Откройте `index.html` в любом браузере. Файл самодостаточен,
единственная зависимость — папка `assets/` рядом с ним (фоны).
Сборка не требуется.

## Что внутри
- `index.html` — экран целиком: разметка, стили, интерактивность.
- `assets/desktop_background.png` — фон для десктопа (используется как есть).
- `assets/mobile_background.png` — фон для мобильной ширины (≤760px),
  переключается автоматически при изменении ширины окна.

## Что откалибровано по эталонному экрану (15.png)
- Один общий Main Content Card (не набор плавающих карточек).
- Синяя рамка карточки и внутренних блоков — как в эталоне,
  а не серая едва заметная граница.
- Иконки — плоские, без кружка/подложки под ними.
- Блок Gia — с синей (индиго) рамкой и текстом, а не заливкой.
- Плотность, отступы, радиусы, вес разделителей — подогнаны под
  эталонный экран, а не под "современный SaaS-дашборд".
- Сайдбар и topbar теперь не белые — сквозь них виден тот же фон,
  что и за карточкой (как в эталоне).

## Демонстрационная панель
Тёмная полоса сверху — инструменты проверки, не часть продукта:
- "Needs Your Attention": показать / скрыть (проверка сворачивания);
- "Recent Transfers": показать / скрыть (проверка сворачивания).

## Нерешённый момент (без изменений с прошлой версии)
В сайдборе нет отдельного пункта "Move Money" — активное состояние
намеренно не проставлено ни на одном пункте, чтобы не менять
навигацию продукта без явного решения об этом.
